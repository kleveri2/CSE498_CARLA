# Installation
To install this software, first install this repository in the same way CARLA is normally built from source:
- Windows: https://carla.readthedocs.io/en/latest/build_windows/
- Linux: https://carla.readthedocs.io/en/latest/build_linux/

Once this repository has been built from source following the steps above, some additional configurations must be made.

# Manual Map Generation
Follow the steps below to generate a map of a manually-selected real-world location:
1. Open the map generation widget located at "CarlaToolsContent/OnroadMapGenerator/UW_OnRoadMainWidget". To see "CarlaToolsContent", the "Show Plugin Content" option must be enabled in the Content Browser's View Options.
2. Right-click the widget and select "Run Editor Utility Widget".
3. Open Open Street Map in a web browser (www.openstreetmap.org).
4. Locate the real-world location to generate a map of.
5. Select "Export" in the top bar and manually set the desired area.
6. If the area is particularly large, click "Overpass API" on the left sidebar and ensure the downloaded file is less than 1GB.
7. Right-click the "Overpass API" option on the left sidebar and copy the link.
8. Return to Unreal Engine and paste the copied link into the "OSM URL" field.
9. Enter a filename for the generated map in the "File Name" field.
10. Apply any desired pre-processing options (see the Pre-Processing section below).
11. Click "Generate".

# Automatic Map Finder Setup
1. Open a command prompt terminal.
2. Navigate to the installed unreal engines independant python3s win64 folder.
     A typical example of this location (if you've installed unreal into the root C drive) is:
     C:\UnrealEngine\Engine\Binaries\ThirdParty\Python3\Win64
3. Run the following commands in any order:
     python.exe -m pip install osmnx
     python.exe -m pip install geopy
     python.exe -m pip install mercantile

# Automatic Map Finder
Instead of manually selecting a real-world location to generate a map from, the software may search for a suitable area with a specific road density. Follow the steps below to use this functionality:
1. Complete steps 1 and 2 of manual map generation (opening the OnRoadMainWidget).
2. Enter the size of the area to find and the desired road density in their respective fields.
3. Enter a filename for the generated map in the "File Name" field.
4. Apply any desired pre-processing options (see the Pre-Processing section below).
5. Click "Find and Generate Map".
6. When a map is generated in this manner, sign data (positions) is automatically recorded.
7. The recorded sign locations are then placed automatically at runtime.
   NOTE: In their current state the signs lack rotation.

# Pre-Processing
Pre-processing allows for modification of the real-world Open Street Map data before the map is generated. This is used for assets that are difficult to modify once the map is generated such as buildings and terrain.
### Usage
Pre-processing options are located in the same widget used for map generation (CarlaToolsContent/OnroadMapGenerator/UW_OnRoadMainWidget). These options are applied when a map is first generated and cannot be changed afterwards. To apply pre-processing options, simply set them in the widget and click "Set Pre-Process Values" before generating a map.

# Post-Processing
Post processing allows changes to be made to a map after it has been generated. Most changes function both in the Unreal Editor and while the simulation is running. If changes are applied while the simulation is running, they are temporary and will be reverted when the simulation ends. If changes are applied while the simulation is not running, they may be permanently saved to the map. Additionally, post-processing presets may be created that allow for post-processing changes to be easily copied from one map to another. Most post-processing options only function on maps generated by CARLA's Advanced Digital Twin Tool.
### Usage
Post-processing options are contained within the post-processing UI widget. The widget may be found at "Content/CSE498/UIWidgets/Post-Processing" and is run by right-clicking it and selecting "Run Editor Utility Widget". The options provided by the post-processing widget are divided into several categories:
- Debris Generation: These options allow for the generation of debris along the roads in the map. Large debris may have physics and collide with vehicles while small debris are purely visual.
- Weather: These options allow for the weather and time of day of the map to be set. These options only function while the simulation is running.
- Road Texture: These options allow for the bulk replacing of the textures of some or all of the roads within the map.
- Presets: These options allow for the creation and loading of post-processing presets. Presets store all of the Debris, Weather, and Road Texture options currently selected. To create a preset, set the "Saved Preset Filename" option to the desired name for the preset and click "Save Preset". Presets may only be saved while the simulation is not running. To load a preset, select the preset you would like to load in the Content Browser, then click the right-facing arrow next to the "Load Preset" option. This will reload the values saved in the preset. Then, click the generate debris buttons and/or the "Apply Road Texture" button as desired to reapply the saved configuration.
- Actor Editor: These options allow for the bulk editing of actors within the map. When you want to edit a category of assets, use this section. To get started, click the "Create Bulk Actor Editor" button (ALWAYS CLICK THIS AFTER BEGINNING PLAY. IF YOU DON'T, THE FUNCTIONS WILL NOT WORK AND YOU'LL HAVE TO RESET AND REPLAY THE MAP.) Now that the editor is created, you can specify the category of the asset you want to change, or the name of the specific asset. Otherwise, you'll be editing everything on the map. On clicking the "Randomize Scale" button, the editor will randomly scale every asset in scope. The "Reset Scale" button will reset these changes. On clicking the "Randomize Significant Object Scale" button, the editor will take all objects significantly in view by a car on the road and randomly scale those assets. The "Significant Object Scale Reset" button will reset these changes. On clicking the "Randomize Rotation" button, the editor will randomly rotate every asset in scope. The "Reset Rotation" button will reset these changes. On clicking the "Randomize Mesh" button, the editor will take all objects significantly in view by a car (fire hydrants, lightboxes, benches, buildings, trees) on the road and change the mesh of those assets to other possible roadside assets. The "Reset Mesh" button will reset these changes.

Throughout all of these catgegories, clicking the right-facing arrow next to an option registers the selected asset(s) in the content browser to that option.
